Нативное приложение для тонкой настройки Windows 11 на C# / WPF, полностью переносящее каталог твиков [Sophia Script for Windows](https://github.com/farag2/Sophia-Script-for-Windows) в графический интерфейс — без необходимости в консоли PowerShell.

Только Windows 11 (25H2+ / Enterprise LTSC 2024). Работает полностью офлайн: приложение не обращается к сети во время работы, все ресурсы и среды выполнения встроены локально.

![Панель управления](docs/screenshots/dashboard.png)

## Возможности

- **97 твиков** в 6 категориях — Конфиденциальность и телеметрия, Интерфейс и персонализация, Система, Игры, Microsoft Defender и безопасность, Контекстное меню — у каждого есть уровень риска, применение/отмена в один клик и кнопка предпросмотра, которая точно показывает, что изменится, прежде чем вы примете решение.
- **Защита при каждом применении**: конфликтующие твики обнаруживаются и блокируются до выполнения любых изменений, для сеансов со средним/высоким риском автоматически создаётся точка восстановления системы Windows, а перед изменениями с высоким риском выполняется проверка состояния системы.
- **Профили**: сохраните текущий набор применённых твиков в переносимый файл `.sophiaprofile` и загрузите его на другом компьютере.
- **Мгновенный нечёткий поиск** по названию и описанию каждого твика.
- **Тема в стиле ар-деко** — единый, фиксированный визуальный стиль (золото на глубоком чёрном фоне, собственная иконография, анимированные переходы) вместо типового системного вида.

![Категория «Конфиденциальность и телеметрия»](docs/screenshots/category-privacy-telemetry.png)

Дополнительные скриншоты — вкладка «О программе» и режим управляемого сеанса — появятся после выхода соответствующих страниц (см. [состояние дорожной карты](#status)).

## Установка

1. Скачайте `SophiaWin11-Setup.exe` из [последнего релиза](https://github.com/Patrickjaillet/sophia-win11/releases/latest).
2. Запустите его и следуйте указаниям установщика. Требуются права администратора — приложение вносит изменения на уровне реестра и системных политик.
3. Запустите **Sophia Script for Win11** из меню «Пуск».

Отдельная установка среды выполнения .NET не требуется — установщик включает автономную сборку.

## Требования

- Windows 11, сборка 25H2 или новее, либо Windows 11 Enterprise LTSC 2024
- Права администратора (повышение прав запрашивается один раз при запуске, а не для каждого твика)

## Статус

Проект находится в активной разработке. `v1.0.0.0` — это релиз-кандидат с заморозкой функциональности, охватывающий полный движок твиков, систему защиты (обнаружение конфликтов, точки восстановления, диагностику состояния), полную оболочку интерфейса и тему/систему анимации в стиле ар-деко. Локализация, вкладка «О программе», управляемые сеансы и подписанный установщик запланированы на следующие версии.

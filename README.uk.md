Нативний застосунок для налаштування Windows 11 на C# / WPF, який повністю відтворює каталог твіків [Sophia Script for Windows](https://github.com/farag2/Sophia-Script-for-Windows) з графічним інтерфейсом — консоль PowerShell не потрібна.

Лише Windows 11 (25H2+ / Enterprise LTSC 2024). Offline-first: жодної залежності від мережі під час роботи, усі ресурси та середовища виконання вбудовано локально.

![Панель приладів](docs/screenshots/dashboard.png)

## Можливості

- **97 твіків** у 6 категоріях — Конфіденційність і телеметрія, Інтерфейс і персоналізація, Система, Ігри, Microsoft Defender і безпека, Контекстне меню — кожен із рівнем ризику, застосуванням/скасуванням в один клік і кнопкою попереднього перегляду, яка показує, що саме зміниться, перш ніж ви це підтвердите.
- **Сітка безпеки на кожному застосуванні**: конфліктні твіки виявляються та блокуються ще до запуску, для сеансів із середнім/високим ризиком автоматично створюється точка відновлення системи Windows, а перед змінами з високим ризиком запускається перевірка стану системи.
- **Профілі**: збережіть поточний набір застосованих твіків у портативний файл `.sophiaprofile` і завантажте його на іншому пристрої.
- **Миттєвий нечіткий пошук** за назвою та описом кожного твіка.
- **Тема Art Déco** — єдина, фіксована візуальна ідентичність (золото на глибокому чорному, власна іконографія, анімовані переходи) замість типового системного вигляду.

![Категорія "Конфіденційність і телеметрія"](docs/screenshots/category-privacy-telemetry.png)

Додаткові знімки екрана — вкладка "Про застосунок" і вигляд керованого сеансу — з'являться після випуску відповідних сторінок (див. [Статус розробки](#статус-розробки)).

## Встановлення

1. Завантажте `SophiaWin11-Setup.exe` з [останнього релізу](https://github.com/Patrickjaillet/sophia-win11/releases/latest).
2. Запустіть його та дотримуйтеся інструкцій інсталятора. Потрібні права адміністратора — застосунок вносить зміни на рівні реєстру та системних політик.
3. Запустіть **Sophia Script for Win11** з меню "Пуск".

Окреме встановлення середовища .NET не потрібне — інсталятор містить автономну збірку.

## Вимоги

- Windows 11, збірка 25H2 або новіша, або Windows 11 Enterprise LTSC 2024
- Права адміністратора (підвищення прав запитується один раз при запуску, а не для кожного твіка)

## Статус розробки

Це активно розроблюваний проєкт. `v1.0.0.0` — реліз-кандидат із заморожуванням функціоналу, що охоплює повний рушій твіків, сітку безпеки (виявлення конфліктів, точки відновлення, діагностику стану), повну оболонку інтерфейсу та систему теми/анімацій Art Déco. Локалізація, вкладка "Про застосунок", керовані сеанси та підписаний інсталятор — у планах на наступні версії.
